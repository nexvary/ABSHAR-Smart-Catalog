## Rules

- Never present a reference image as the exact listed SKU unless the source clearly matches that SKU or product family.
- Reference imagery in the storefront is labeled `صورة مرجعية مفتوحة` when it does not come from the product record itself.
- Prefer manufacturer-approved or Wikimedia Commons imagery with explicit reuse rights.
- Do not copy protected product photography from retailer/manufacturer sites unless reuse permission is explicit.
- Keep public attribution available in `assets-credits.php`.
- Any future asset must be added to this file before release.
